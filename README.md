Leonida Nights is a top-down open-world crime game in the spirit of GTA: walk the streets of Leonida City, steal a car, run delivery and cash-collection missions for money, and outrun the LCPD as your wanted level rises. Pure static HTML/JS — no build step, no network requests at runtime, no sound.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```

Controls: WASD / arrow keys to walk and drive, E to enter or exit a car, P or Esc to pause, Space to start or restart. Follow the yellow marker to run each mission before its timer runs out; every completed mission pays cash and raises your wanted level, and the police chase harder the more stars you have. Get busted (caught on foot by the cops) or wasted (health hits zero) and it's game over.
